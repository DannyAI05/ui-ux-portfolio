## About the Project

WAKHU is a personal UI/UX design portfolio created to showcase my design concepts, creative thinking, and approach to building intuitive digital experiences.

The portfolio serves as a central space for presenting my Figma design projects, exploring user-centered design principles, and demonstrating my interest in creating visually appealing and functional interfaces.

The website combines a futuristic visual identity with a clean, structured layout to create an engaging experience for visitors.

## Design Philosophy

My design approach focuses on three core principles:

- **User-centered design:** Creating interfaces that prioritize the needs and expectations of users.
- **Visual clarity:** Using typography, spacing, color, and hierarchy to communicate effectively.
- **Meaningful interactions:** Designing experiences that feel intuitive, engaging, and easy to navigate.

## Features

- Modern, futuristic portfolio design.
